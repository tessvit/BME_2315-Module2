This repository contains data files and a final Jupyter Notebook which analyzes patient data regarding FSHD. The purpose of this project is to determine which biomarkers are the most sensitive to change: TA fat fraction in right and left legs and a timed 10 meter walking/running test. We hope the results from this project will encourage future clinical studies to measure these outcomes when considering FSHD treatment.
